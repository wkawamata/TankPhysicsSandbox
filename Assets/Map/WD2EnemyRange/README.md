# WD2 敵攻撃テストマップ

マップ一覧から WD2EnemyRange を選択します。開始位置は (0, 2, -20)m。
200m四方の平地。正面の TurretA は通常弾、左の TurretB は球形特殊弾、右の TurretC は箱形特殊弾を発射します。
右奥 (30, 1.5, 20)m の TurretMixed は3つの砲台を持ち、近づくと3種類の弾を発射します。

攻撃の a–g は探知50m、射程30m、射撃25m、弾速1m/s、間隔3秒、旋回5度/秒、許容±3度。
通常弾半径0.25m、特殊球半径0.5m、特殊箱の幅・高さ・奥行きは1.5・0.5・2mです。
敵HP60、通常弾ダメージ20。通常弾と迫撃砲は敵通常弾を破壊し、特殊弾は破壊しません。

敵エディタの保存先はこのフォルダの enemy_types.json になります。
テンプレートを編集して Save、Reset Tank で配置済みの敵へ反映します。
マップエディタも同じJSONを自動で読み込み、4種類の敵を配置できます。配置は Manifest.json へ保存します。

被弾ダメージ100、HP100、開始残機3。Lost後は被弾位置で復帰し、3回LostでGameOver。
Continue はマップ開始位置へ戻り、敵も初期状態に戻します。
