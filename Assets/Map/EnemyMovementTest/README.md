# 敵戦車ユーザテスト

最新のReleaseビルドは `scripts/run-enemy-movement-test.bat` から起動する。
既存のマップ選択でも `EnemyMovementTest` を選択して開始できる。
初期位置は X=-20 / Z=-45、前方は +Z。入力割り当ては既存の自機設定を使用する。

## 確認する順序

1. 初期位置から、灰色コースの敵（X=-20）が遠距離で往復することを確認する。
2. 灰色コースを進み、敵から30m以内で履帯物理へ切り替わることを確認する。離れて40m以上になると、安全な走行面へ対応できた時点で簡易移動へ戻る。
3. 中央（X=0）の敵は35m以内で発見すると追跡する。10mで停止し、照準・射程・遮蔽条件がそろうと射撃する。茶色の壁を使って視線を遮り、最後の観測位置への捜索を確認する。
4. 青い橋（X=30）はZ=0〜20の上り坂、Z=20〜40の高さ4mの橋、Z=40〜60の下り坂。敵は橋と出口を往復する。近づいて物理での坂道走行も確認する。
5. 橋の中央の下へ移動し、上側の敵が上下の面を取り違えないことを確認する。上下は橋の両端だけで接続している。
6. Enemy Unit Editorで距離・減速・到達半径などを変更し、リセットなしで挙動が変わることを確認する。リセットで初期配置を再開できる。Enemy movement statusでは各敵の物理/簡易モード、距離、HP、グループ行動、経路停止理由を確認できる。

自機と敵は同じ戦車表示を使用する。車輪・履帯の表示は既存の表示設定に従う。
敵の物理当たり判定は現在車体箱だけで、表示砲塔には独立した当たり判定がない。
一体のglTF車体・側面は剛体表示で、車輪・履帯インスタンスが足回りを表現する。

## 注意する観察点

- 切り替え時の位置・姿勢の飛び、旋回の振動、停止距離、坂道での転倒・停止。
- 40mを超えても空中・不安定・走行面対応不能の場合は物理を継続する。
- 簡易移動はJolt衝突で進路を決めない。壁の位置はこのマップの走行格子にも反映済み。
- 撃破後の自動復帰、複数台の隊列、動的な倒壊はまだ対象外。

`Manifest.json`、`enemy_types.json`、`navigation.json`、`Models/Course.gltf` はマップローカルのデータ。
コース生成を変更する場合は `scripts/generate_enemy_movement_map.py` を編集して実行する。
## 移動が制動される場合

ゲームパッドの迫撃砲ジェスチャー（左右の横方向を外側へ倒す）が入ると、開始待ちと姿勢保持中は移動を制動する。画面上部にMovement heldと理由を表示する。姿勢完成前にジェスチャーを離した場合は開始待ちをキャンセルして移動へ戻る。完成後はジェスチャーを離すと車体を下げ、復帰後に通常移動へ戻る。撃破待機・残機ゼロ・一時停止も別の停止条件なので、HP/LivesとPause表示を合わせて確認する。
