# Step 3.1～3.2 入力境界と特殊入力認識

左右レバーの水平入力を物理制御から分離する `SpecialActionRecognizer` を追加した。

- 左レバー左＋右レバー右: `MortarRequested`
- 左右レバー同方向（負）: `RollLeftRequested`
- 左右レバー同方向（正）: `RollRightRequested`
- 内向き・不一致入力: `None`

開始閾値は0.70、解除閾値は0.20。認識成立後はラッチされ、入力を保持しても再発火しない。次の認識には両レバーの中立復帰が必要である。非有限値は拒否し、中立入力で再アームする。

迫撃の外開き判定を同方向ローリングより先に評価し、入力の意味が衝突しない境界を固定した。物理車体やUIにはまだ接続していない。

`TankPhysics.SpecialActionRecognizer` の単体テストで方向、優先順位、保持、解除、中立復帰、非有限入力を確認した。
