# Request 005 日本語要約: Debug Camera仰角制限の緩和検討

- 現在のRtPbrSurvey Arcball上限は`1.4 rad`、約`80.214度`。
- Tank側はDebug切替時の角度変化を防ぐため、当面同じ値へ制限する。
- 上流では上限を88度へ緩和できるか検討してほしい。
- 水平回転はワールドY軸基準を維持する。
- 90度ちょうどの特異点は許可しない。
- 通常角度と上限付近について、X/Yドラッグの自動テストを追加する。
- 88度のカメラからArcballへ切り替えても角度が飛ばないことを確認する。
- 実装方法は固定上限88度でも、90度未満に制限したhost設定値でもよい。
- Tank固有概念はRtPbrSurveyへ追加しない。
